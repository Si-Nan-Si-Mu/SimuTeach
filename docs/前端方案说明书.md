## 1. 技术选型与架构

### 1.1 技术选型（摘要）

采用 **Vue 3 + Vite** 构建无服务端渲染的单页应用；图表使用 **ECharts**。与智能体平台的对接集中在独立的工作流客户端脚本（非 npm 包），通过浏览器全局对象向业务层暴露发送消息、拉取报告等能力。样式采用常规组件作用域样式与全局样式，并做必要的移动端适配，细节不展开。

### 1.2 逻辑架构

应用由根壳层统一维护**当前模式**（专项一对一训练 / 课堂多生模拟）、**当前选中的人格**、**会话标识**以及按人格隔离的对话与情绪快照。专项与课堂两个场景复用同一套人格档案（三名学生），但向外发出请求时走**不同的通道与配置**（专项 Bot、课堂 Bot、报告与主动轮询共用的 HTTP 基址等）。工作流返回可能是 SSE 流或非流式 JSON 字符串，前端需统一抽取「学生台词」再进入界面，避免整段 JSON 误当作对话展示。

课堂场景在业务上区分两条 outbound 路径：**教师手动发言**仍经课堂专用工作流（与其他场景密钥隔离）；**定时或调试触发的主动会话**则绕过工作流，以直连 HTTP 提交空内容并携带主动标记，且仅当响应满足约定字段时才映到头上的对话气泡。

配置在构建阶段由环境变量注入，开发时报告类接口可通过同源代理转发以降低浏览器跨域限制。

### 1.3 文档与产物

说明性网页版 `前端方案说明书.html` 内嵌 **SVG 流程图**（不依赖外网脚本即可在浏览器中查看），便于 **Word → 打开该 HTML** 或 **打印为 PDF** 再转入公文流程。文末仍保留界面截图占位，供后续贴图。

## 2. 核心能力（产品视角）

### 2.1 角色选择

侧栏维护三名学生的档案与当前选中项。切换学生时重建专项侧会话标识，并向工作流侧发出人格切换语义，使后续回复与新人格一致。每名学生的情绪状态分开记忆，避免来回切换时数值串扰。支持在弹窗中调节五维人格参数并实时反映到雷达预览；关闭弹窗时一般不强制重置整段训练，以减少误操作成本。

### 2.2 点名与广播（课堂）

课堂中可点选一名学生或保持「未点名」以表示面向全班。发言文案随之在「对某生」与「广播」之间区分。请求中会携带广播范围及对象标识，便于后端区分语境。视觉上可将同一段全班回复集中到一名代表位置展示，以免重复三条相同气泡；主动轮询默认也采用代表位展示。

### 2.3 对话形态

**专项**：教师输入与快捷教学策略标签一并发出；回复经工作流以流式为主返回，前端归并为完整一句学生话并写入对话区历史按人格分桶。**课堂手动**：教师输入经课堂工作流返回，结果进入事件流与头顶气泡。**课堂主动**：仅直连 HTTP，空正文 + 主动标记；仅当响应含约定的主动话术字段且未命中「无内容」占位时更新气泡，其余响应静默。

### 2.4 情绪可视化

专项侧以愉悦、激活、焦虑等维度展示当前状态与时间序列，并可在工作流回包中解析情绪相关调试信息以刷新看板；教师操作标签也可触发轻微的本地情绪扰动作为辅助反馈。课堂侧对三名学生分别维护简化情绪标量并在控制台区域呈现。训练报告中若带有调试情绪块，以独立小节展示，与对话气泡解耦。

### 2.5 训练报告

在达到最低对话量要求后，可由侧栏触发报告：先进入全屏加载态，再向报告接口发起带「评估」语义的 JSON 请求；返回体经解包后提取结构化评估块与可选调试块，用于概况、维度得分、改进建议等区块；若后端未提供结构化评估，则回退到基于本地历史的启发式打分与文案。能力雷达与条形图优先采用后端大类得分。

## 3. 与后端协作要点

### 3.1 通道划分

| 业务 | 通道概要 |
|------|-----------|
| 专项对话 | 智能体 SSE 工作流，专用应用密钥 |
| 课堂手动 | 同协议，独立课堂应用密钥 |
| 课堂主动 | 直连类 Chat Completions 的 HTTP，请求体含主动标记与空消息 |
| 训练报告 | 同源 HTTP 配置，请求体含评估标记 |

### 3.2 请求与响应（概念）

工作流侧为 POST + 流式响应，正文包含会话标识、内容、应用密钥及自定义业务字段（如策略标签、模型名、课堂范围等）。报告与主动轮询为 POST + JSON，使用 API 密钥或 Bearer 头（以部署配置为准）。前端需兼容「流式增量」与「单次 JSON 字符串」两种回复形态，并从中解析助手话术；课堂主动轮询另有一套「是否展示」的判定，与手动路径不同。

### 3.3 状态与并发

根层持有模式、当前人格、会话 id、分人格对话与情绪缓存；工作流脚本可通过约定好的全局对象读取扩展字段以供报告等使用。课堂侧对工作流与主动轮询使用简单忙标志，避免交替点击造成叠套请求。

### 3.4 异常与降级

网络失败、跨域或 HTTP 错误时，专项与课堂倾向于在对话区或课堂事件区给出可读提示并记录控制台标签，不阻断整页。未配置课堂密钥则跳过课堂请求。主动轮询在地址缺失或非成功响应时清空气泡并记录原因。报告请求失败或返回不可解析时，关闭加载层并尽量依赖本地历史打开简版报告；密钥落在前端 bundle 中的部署需知悉安全风险，生产建议走网关或代理。

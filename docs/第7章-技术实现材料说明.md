### （2）接口对接说明（ADP 平台 API 与本项目实际调用）

以下接口均来自当前代码实现（`src/`、`vendor/front/js/workflow.js`、`vite.config.js`）。

#### A. 智能体对话 SSE 接口（ADP）

- **接口名称**：`qbot/chat/sse`
- **HTTP 方法**：`POST`
- **接口地址**：`https://wss.lke.cloud.tencent.com/v1/qbot/chat/sse`
- **使用场景**：
  - 专项模拟对话
  - 课堂手动发言
  - 教学文档分析（上传后将 `file_url` 作为 `content/message`）
- **鉴权方式**：请求体字段 `bot_app_key`（ADP 应用密钥）

请求参数（核心字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `request_id` | string | 请求唯一标识 |
| `content` | string | 输入正文（文档分析时为文件 URL） |
| `message` | string | 与 `content` 保持一致 |
| `session_id` | string | 会话标识（2-64，字母数字下划线） |
| `bot_app_key` | string | ADP 应用密钥 |
| `visitor_biz_id` | string | 访客标识 |
| `incremental` | boolean | 增量返回开关 |
| `custom_variables` | object(map[string]string) | 业务扩展字段 |
| `stream` | string | 常用 `enable` |
| `workflow_status` | string | 常用 `enable` |
| `evaluation` | boolean | 报告语义标记（普通对话一般为 `false`） |

返回格式：

- **主要返回**：`text/event-stream`（SSE）
- **兼容返回**：部分场景可能返回 JSON；前端已做 SSE/JSON 双分支解析

示例请求体（节选）：

```json
{
  "request_id": "req_sess_xxx_1710000000000",
  "content": "老师您好，请回答这个问题",
  "message": "老师您好，请回答这个问题",
  "session_id": "sess_xxx",
  "bot_app_key": "******",
  "visitor_biz_id": "teacher-001",
  "incremental": true,
  "evaluation": false,
  "custom_variables": {
    "role": "teacher",
    "trigger": "互动"
  },
  "stream": "enable",
  "workflow_status": "enable"
}
```

#### B. 存储凭证接口（ADP OpenAPI，经本地代理）

- **接口名称**：`DescribeStorageCredential`
- **调用路径（前端）**：`POST /api/describe-storage-credential`
- **上游接口**：`https://lke.tencentcloudapi.com`
- **使用场景**：教学文档分析文件上传前，获取临时上传凭证/地址
- **鉴权方式**：服务端代理使用 `TC3-HMAC-SHA256`（`VITE_ADP_SECRET_ID` / `VITE_ADP_SECRET_KEY`）

请求参数（前端到代理）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `BotBizId` | string | 可选，机器人业务 ID |
| `FileType` | string | 文件类型后缀，如 `docx` |
| `IsPublic` | boolean | 是否公有 |
| `TypeKey` | string | 常用 `offline` |

返回格式：

- `application/json`（代理透传上游 JSON）
- 前端会解析出 `uploadUrl/workflowUrl/headers/formFields/fileUrl/objectKey` 等可用信息

---

#### C. COS 上传代理接口（本地中转）

- **接口名称**：`/api/cos-upload`（项目内代理接口）
- **HTTP 方法**：`POST`（代理再转发为 `PUT` 到签名 URL）
- **使用场景**：浏览器跨域受限时，通过本地代理上传文件
- **鉴权方式**：使用上一步凭证接口返回的签名 URL 与头信息；请求头需带 `x-upload-url`

请求参数：

| 字段 | 类型 | 说明 |
|------|------|------|
| Header `x-upload-url` | string | 目标上传 URL（必填） |
| Body | binary | 文件二进制内容 |
| Header `Content-Type` | string | 文件 MIME |

返回格式：

```json
{
  "ok": true,
  "status": 200,
  "contentType": "...",
  "body": "..."
}
```

---

#### D. 训练报告接口（项目直连 HTTP，兼容 ADP Chat Completions 形态）

- **接口名称**：Chat Completions 风格评估接口
- **接口地址**：`VITE_REPORT_HTTP_URL`（开发可经 `/api/report` 代理）
- **HTTP 方法**：`POST`
- **使用场景**：课堂模拟内点击“结束 · 生成报告”
- **鉴权方式**：`Authorization: Bearer <apiKey>`，并在 JSON 中携带 `api_key`

请求参数（核心字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `messages` | array | 对话数组（当前实现最小化为 1 条 user） |
| `evaluation` | boolean | 固定 `true`，表示评估/报告模式 |
| `api_key` | string | 接口密钥 |
| `temperature/top_p/max_tokens/stream/user` | number/bool/string | 可选参数 |

返回格式：

- `application/json`（推荐）
- 若返回文本，前端也可兼容兜底处理

示例请求体（节选）：

```json
{
  "messages": [{ "role": "user", "content": "" }],
  "evaluation": true,
  "api_key": "******",
  "stream": false
}
```

### （3）数据库设计

#### 3.1 结论

本项目当前为**纯前端应用**，未使用 MySQL/PostgreSQL/SQLite 等服务端数据库，也未包含后端建表脚本。  
数据持久化主要为浏览器本地缓存与导出文件：

- `localStorage`：工作流历史记录
- 内存响应式状态：会话态、情绪态、分析结果态
- 文件导出：JSON / Markdown / PDF

#### 3.2 本地持久化结构（可作为“数据库设计”替代说明）

本地键名：`workflow_history_data`

记录对象字段如下（来自 `vendor/front/js/workflow.js`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 记录主键（前端生成） |
| `session_id` | string | 会话 ID |
| `request` | string | 请求内容 |
| `response` | string | 响应内容 |
| `character_id` | string/null | 人格 ID |
| `trigger` | string/null | 触发标签 |
| `created_at` | string | ISO 时间 |

可提交材料建议：

1. 本 `md` 文档（说明未使用服务端数据库的原因与当前持久化结构）；  
2. 如评审要求“表结构”，可附上等价 SQL 设计草案（仅用于说明，非真实线上库）：

```sql
CREATE TABLE workflow_history_data (
  id VARCHAR(64) PRIMARY KEY,
  session_id VARCHAR(64) NOT NULL,
  request TEXT NOT NULL,
  response TEXT NOT NULL,
  character_id VARCHAR(32),
  trigger VARCHAR(32),
  created_at DATETIME NOT NULL
);
```
